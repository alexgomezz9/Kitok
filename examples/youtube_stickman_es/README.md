# Configuración de un episodio ilustrado

Copia [configuracion.json](configuracion.json) a la carpeta creada con `init`.
Sustituye la ruta de referencia por fotogramas interiores reales y completa estilo,
personajes y voz a partir de los materiales aprobados. No se incluyen guiones,
imágenes definitivas ni credenciales. No es una muestra de estilo aceptada.

Kitok genera el borrador temporal y la plantilla de dirección a partir del SRT
real. Codex completa los prompts por ID y genera las imágenes fuera del renderer;
no se programa un componente nuevo por historia.
[Flujo completo y límites](../../docs/youtube-stickman-es.md).
