# Auditoría de Kitok — 15 de octubre de 2026

Alcance: código local y cambios previos, ramas/remoto, motor corto/largo,
configuración de desarrollo y propuesta de evolución. No se han generado vídeos
con proveedores de pago, publicado contenido, creado credenciales ni realizado
OAuth. [Roadmap](../roadmap.md) distingue lo pendiente de lo implementado.

## Evidencia y cambios reales

Se contrastaron servicios, contratos HTTP, frontend, pruebas, CLI, scripts y
configuración permitida. Se encargaron auditorías independientes de motor y
entorno Codex. FFmpeg/ffprobe locales: 6.1.1. Las pruebas usan proveedores simulados;
algunas ejercitan FFmpeg real con medios sintéticos. Las referencias oficiales de
YouTube y Codex se consultaron en web, sin autenticación de cuentas.

La primera ejecución de la suite tenía 329 éxitos y dos fallos. Se comprobó que los
contratos vigentes eran música 0.06 y disclosure opcional false. Se ajustaron tests
a esos valores y se verificó por separado disclosure true explícito, sin cambiar
política de producción. La suite base resultante pasó con 332 pruebas. Los
resultados finales de gates y revisión se registran al final de este informe.

Cambios de esta ejecución:

- Se versionaron los módulos nativos existentes que el estudio ya importaba:
  longform, rendering, media, providers y stock. Antes estaban en disco pero un
  clone no los obtenía. Commit f1dbc90.
- Se separaron código, ejemplos sintéticos, documentación vigente e historia. No se
  movieron guiones/definiciones activas con referencias internas.
- Cola, backups y egg-info dejan de versionarse; la cola activa sigue en su ruta.
  Pilotos antiguos, imports, benchmarks y snapshots sueltos se preservan en local/
  con manifiesto de rutas y hashes. No se borraron vídeos ni .env.
- El CLI de consulta admite una instalación sin cola y no crea estado; el estudio
  puede crear una cola vacía. La ausencia de cola para generación CLI no inventa
  contenido ni inicia trabajos.
- Se incorporó make verify/verify-browser, CI y el protocolo del coordinador.
- Se escribieron propuestas multicanal, director y YouTube; no se implementaron.

## Hallazgos priorizados

No se confirmó un P0. P1 indica bloqueo para autonomía o riesgo de duplicar coste;
no implica que todos los usos manuales actuales fallen.

| Prioridad | Evidencia y escenario | Consecuencia / dependencia |
|---|---|---|
| P1 resuelto | Imports native apuntaban a fuentes fuera de Git | Clone incompleto; módulos y tests ya versionados |
| P1 pendiente | fish_voice.py reintenta POST tras timeout/transporte/5xx; simulación ReadTimeout produjo tres POST | Resultado/cobro ambiguo. Requiere ledger, estado unknown y reconciliación antes de autonomía |
| P1 pendiente | pipeline.py planifica diálogo antes de recuperar mpt_task_id; generation.py vuelve a sintetizar voces | Un reintento puede repetir Fish aunque MPT ya esté enviado; persistir artefactos y separar fases |
| P1 pendiente | native conserva workspace fallido pero CLI rechaza resume y no reutiliza etapas | Reintentar trabajo vuelve a pagar voz; recuperación por etapa antes del director |
| P2 pendiente | Cache Pexels comparte asset_id.mp4.part; smoke omite lock del trabajo; exclusión actual no cubre varios procesos | Antes de concurrencia multicanal: partes únicas y locks por activo/recurso |
| P2 pendiente | reset_failed borra mpt_task_id tras fallos/timeout | Reconciliar tarea remota antes de reenviar, conservar intentos históricos |
| P2 pendiente | longform_studio carga longform.py raíz dinámicamente | Un wheel instalado sin checkout no aporta el CLI; documentado, empaquetado pendiente |
| P2 pendiente | Native escribe MP4 final antes del manifest | Fallo lateral deja MP4 válido con trabajo fallido y salida existente; confirmar bundle transaccionalmente |
| P2 pendiente | JSON largo corrupto puede abortar carga del conjunto | Aislar registro dañado y mostrar recuperación sin perder otros trabajos |
| P3 pendiente | Sidecar corto no atómico ni ligado a hash/config/versión | Trazabilidad y recuperación limitadas; incorporar manifest común |

Referencias de implementación: src/kitok/fish_voice.py, pipeline.py, generation.py,
stock/cache.py, rendering/native.py, longform_studio.py y longform.py raíz.
Estos riesgos no se han ocultado cambiando defaults ni eliminando protecciones de
publicación. El primer incremento recomendado es asegurar las operaciones de
pago, no lanzar producción autónoma sobre estos reintentos.

## Decisiones y límites de entrega

Se mantiene guardado local sin Google Drive. El motor largo nativo sigue
experimental y MPT conserva sus rutas existentes. **No se puede borrar
MoneyPrinterTurbo** si se quieren conservar shorts Pexels y largos MPT.
La migración completa se separa en el roadmap y exige equivalencia demostrada.

La autonomía de desarrollo queda apoyada por comandos y revisiones observadas,
con límites explícitos. No se promete que un hook global ejecute universalmente
el protocolo ni que un YAML nuevo ya haya pasado en GitHub. La autonomía editorial
y la recuperación de pagos todavía no están implementadas.
